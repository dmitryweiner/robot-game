# План: Игра 1 — «Ремонтная консоль» (глава 01)

## Источник

Глава [`01. Ремонтная консоль.md`](../../../robot-talks/01.%20Ремонтная%20консоль.md).
Мальчик через ремонтную консоль робота диагностирует и чинит отказавшие
драйверы северного моста: `ls`, `cat`, `echo`, `wc`, `tail`, `grep`, пайпы
`|`, редиректы `>` `>>` `<` `2>` `2>&1`, `chmod +x`, запуск скрипта `./…`.

## Цель мини-игры

Симулятор Unix-консоли с виртуальной файловой системой. Игрок вводит
настоящие shell-команды; финал — успешный запуск `./drivers/nb_init.sh`
после того, как выданы права на исполнение.

## Ключевые решения

- **Движок не зависит от React.** `shell/fs.ts`, `parser.ts`, `commands.ts`,
  `interpreter.ts` — чистые функции/данные, тестируются напрямую в Vitest без
  рендеринга компонентов. `Terminal.tsx` — тонкая обвязка.
- **Immutable FS.** Каждая мутирующая операция (`echo >`, `chmod`) возвращает
  новый корень дерева (`structuredClone` + правка копии), не трогая старый —
  проще для React state и для тестов на неизменность.
- **Только команды, нужные для сюжета** реализованы по-настоящему: `pwd`,
  `ls` (-l, glob `*`), `cat`, `echo`, `wc` (-l), `tail` (-n), `grep`
  (подстрока), `chmod` (+x/-x), `journalctl`, `cd`, плюс исполнение файла по
  пути (`./…`). `&&`/`||` из главы не реализованы — они только упоминаются
  риторически и не участвуют в решении головоломки; сознательно вынесено за
  рамки MVP.
- **Подсказки не блокируют.** `objectives.ts` — эвристика
  `detectStageIndex(line, result)`, которая двигает индекс подсказки в
  сайдбаре вперёд, когда действия игрока похожи на очередной сюжетный шаг.
  Игрок может пропустить шаги (например, сразу сделать `chmod +x` и
  запустить скрипт) — условие победы совершенно не зависит от прогресса по
  подсказкам, оно завязано только на событие `script-success` от
  интерпретатора.
- **Канонiчный журнал.** `journal.ts` — фиксированный список строк лога с
  «шумом» (обычная загрузка) и несколькими `ERROR`-строками, из которых
  только часть касается `nb_motor_left` — так `grep ERROR` даёт осмысленный,
  а не тривиальный результат.

## Не вошло в объём (сознательно)

- Полный набор Unix-утилит, которые робот просто перечисляет в конце главы
  (`find`, `sed`, `awk`, `ps`, `tar`, `ssh`, …) — они упомянуты в диалоге для
  общего кругозора, но не нужны для решения; не реализованы.
- `less`, `head`, `df`, `du`, `free`, сеть — не задействованы в этой главе.
- Автодополнение по Tab.

## Тесты

- `tests/shell/fs.test.ts` — виртуальная ФС, резолвинг путей, glob.
- `tests/shell/parser.test.ts` — токенизация, редиректы, пайпы, синтаксис.
- `tests/shell/interpreter.test.ts` — сквозной прогон всей сюжетной цепочки
  команд главы, включая permission denied → chmod → успешный запуск.
- `tests/shell/objectives.test.ts` — эвристика подсказок.
- `tests/components/Terminal.test.tsx`, `RepairConsoleGame.test.tsx` — React
  UI поверх движка.
- `tests-e2e/*.spec.ts` (Playwright) — визуальная проверка хаба и полного
  прохождения игры в браузере.
